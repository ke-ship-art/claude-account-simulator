# Account Weather · AI 账号生存模拟器

一个非官方、纯本地的单人 Web 仿真游戏。玩家创建虚拟账号，使用内置 Mock AI，对话消耗模拟额度；环境、设备、支付与使用节奏会形成风险证据，进而触发提醒、验证、限流、审核、冻结或终止。申诉审核使用账号历史、证据强度和可复现随机种子推演。

**这不是 Anthropic 或 Claude 的产品。** 游戏不连接真实账号、模型、支付或客服，也不索取真实密码、API Key 或支付资料。风险评分、阈值、概率与额度数字均为独立设计的虚构规则，不代表任何真实服务的内部机制。

## 启动

需要 Node.js 20+。

```bash
cd claude-account-simulator
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；单元测试：`npm test`。

本机验收时 npm 官方仓库 DNS 无法解析，因此使用工作区已有的依赖完成了构建和测试。源码依赖在 `package.json` 中完整声明；网络正常的环境可按上述步骤独立安装。

## 游玩路径

1. 选择模式、虚拟地区、网络、设备、注册方式、使用画像和随机种子。
2. 在产品视角创建对话、切换模型、添加虚拟附件，并关注五小时及七日额度。
3. 在设置里改变环境、切换会话、测试登录与验证；在订阅页使用游戏币升级、降级或安排取消。
4. 从通知中心阅读限制信息，提交申诉或补充材料。使用顶部时间按钮、用量页或实验室推进模拟时间。
5. 在实验室查看风险走势图、事件贡献、原始日志；调节全局参数和事件权重、注入事件、比较种子。
6. 通过账号生涯页回顾时间线和成就，或创建新档案探索另一条命运。

进度保存在浏览器 `localStorage` 中，多个档案可以切换。附件目前只保留名称与大小，不读取或上传文件内容。

## 规则结构

- `src/game/types.ts`：账号、事件、聊天、申诉与账单类型。
- `src/game/data.ts`：虚构额度、模型消耗、模式参数、成就定义。
- `src/game/engine.ts`：纯状态转移函数、风险事件衰减、种子随机数、订阅与申诉流程。
- `src/game/persistence.ts`：版本化本地存档。
- `src/game/mockAi.ts`：无外部 API 的模拟对话回复。
- `src/App.tsx` 与 `src/styles.css`：玩家视角和实验室界面。

风险由事件权重、半衰期、模式参数、环境稳定度、支付风险、信誉和历史限制共同计算。状态转移还使用账户种子的伪随机数，因而相同初始条件和事件顺序可以复现结果。付费计划提供更高游戏额度，但不豁免风险评估。

## 验收记录

- `npm run build`：通过。
- `npm test`：12 个测试通过，包括衰减、确定性、状态转移、额度重置、订阅续费与取消、申诉成功和失败、旧存档迁移、持久化与边界输入。
- Chrome 原生 CDP：注册 → 对话回复 → 额度消耗 → Pro 升级 → 风控终止 → 申诉 → 补充材料 → 恢复账号；检查页面脚本异常，结果为 0。刷新后恢复状态仍保留。
- 390px 移动视口：无横向溢出。
- Chrome 后续回归：订阅到期取消、聊天置顶和地区变化已写入存档。

## 当前边界

- 内置 Mock AI 使用主题模板生成回复，不具备真实大模型的推理能力。
- 附件只模拟元数据；不会解析文件正文。
- 不提供真实跨设备同步；存档只在当前浏览器内。
- 本游戏未实现官方产品的全部功能，公开计划结构仅作体验参考。
