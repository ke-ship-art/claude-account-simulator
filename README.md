# Claude · 本地体验环境

非官方、仅供本地个人使用的 Claude 风格网页客户端与账号状态模拟器。它不连接真实 Claude 账号、订阅、支付或客服。虚拟风控、额度估算和结算都属于本项目的模拟规则。

## 启动

需要 Node.js 20+。Windows 双击 `start-claude-local.cmd` 即可启动本地服务并打开浏览器；这是唯一的双击启动脚本。首次运行若缺少依赖，先在本目录执行 `npm install`。关闭启动窗口可结束由它启动的服务；若服务已在运行，脚本会重新打开网页并退出。

也可手动执行：

```bash
npm install
npm run dev
```

打开终端给出的本地地址。构建：`npm run build`；单元测试：`npm test`；Chrome 浏览器验收：`npm run test:e2e`。启动器只复用带有本机模型网关的当前版本；若旧服务仍占用 5173，会尝试 5174–5183。

## 日常使用

先选择虚构地区和身份，完成页面内模拟短信验证，再创建虚拟账号。不需要真实手机号、密码或真实邮箱；不支持地区会在建档前被阻断。建档后可以使用聊天、搜索、项目、Artifacts 列表、用量、订阅和通知。旧版存档继续使用相同 localStorage 键读取；关闭网页期间到期的延迟安全检查会在下次打开时补执行，快进时间使用同一调度器。聊天、风险事件与检查结果保存在当前浏览器。常见文本附件（最大 256 KB）会保存在本地对话中；配置真实模型服务后，其正文会随消息发送给该服务。

默认是**离线体验**：回复只说明当前为演示模式，不假装提供真实模型能力。若要获得真实回答，从「设置 → 开发者设置」进入独立的 Simulator DevTools，配置 Anthropic API、OpenAI 兼容服务或 Ollama。模型请求通过只监听本机的 Node 网关转发，支持 SSE/NDJSON 流、停止生成、连接超时和流中断。模型地址、映射、思考强度及 API 密钥会在点击「保存配置」后持久保存在当前系统用户的数据目录；保存成功或失败会在页面右下角明确提示。重启服务后自动恢复。Windows 使用当前用户的 DPAPI 加密配置文件，位置为 `%LOCALAPPDATA%\ClaudeAccountSimulator\provider-config.dat`；浏览器存档与会话存储不保存密钥。同一 Windows 用户下运行的本地程序仍有能力访问该用户的凭据。Linux/macOS 将配置写入用户配置目录并设为仅文件所有者可读写。若从旧版升级，旧版只存在进程内存的密钥无法迁移，需要重新输入并保存一次。切换提供方地址时旧密钥自动清除；改回「离线体验」并保存会清除文件中的密钥。远程地址要求 HTTPS 且不能解析到内网地址；Ollama 默认只允许本机回环地址，也可在开发者设置中逐个显式信任 WSL2 / 局域网私有 IP 的 `:11434` 服务。真实 API 调用可能产生提供方费用，与本地虚拟订阅无关。

模型选择器列出 Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5。Anthropic API 直接使用官方 ID；OpenAI 兼容服务和 Ollama 需为每个按钮填写其实际模型 ID。API 模型支持和 claude.ai 套餐可用性分开记录。当前本地规则允许 Free 使用 Sonnet、Haiku；Pro 增加 Opus；Max 增加 Fable。官方 Pro 的 Fable 用量积分机制尚未在本地实现。

## 模拟实验

DevTools 可切换地区、网络、IP 声誉、设备、浏览器和并发会话，查看风险贡献、时间线和状态变化，推进虚拟时间、注入事件、调整风险参数与测试 Access Gate。还可切换实验模式、关闭单项风险规则、用相同或新随机种子创建档案，以及导出或导入账号 JSON。导出文件包含聊天和文本附件内容，请在本机妥善保存；导入会创建新账号，不覆盖旧档案。更改参数会写入当前账号并改变实际准入或风险响应。内容策略分类与账号安全响应分离：普通请求、谨慎话题和本地拦截分别处理；重复拦截才形成账号行为信号。具体词表仅用于测试，**不是 Anthropic 的内容策略实现**。

普通模型拒答、本地前置检查、上游安全拦截、服务错误、网络错误和停止生成会分别标记，并保留原始用户消息及实际收到的回复。一个会话生成时可以切换到另一会话继续使用；刷新后，未完成的回复会保留已收到的文字并标为「流中断」。聊天搜索可命中消息正文并跳转到具体消息。文本附件可用按钮、拖放或粘贴添加；输入框随长文本增长。受限账号不能继续聊天，可以查看通知、提交或补充申诉、导出档案及删除本地账号；DevTools 可推进审核时间。虚拟结算位于独立的本地沙盒界面，输入本地确认码 `123456` 完成模拟付款，错误代码产生验证失败；模拟支付故障只在开发者设置中配置，不接受银行卡或真实身份资料。账单生成后的 7 个模拟日内可执行一次虚拟退款；取消订阅会在当前账期结束后生效。

未发送的输入和附件按会话暂存在当前页面内存中，切换会话时不会串到其他聊天；提交后才写入浏览器存档，刷新页面会清除未发送草稿。模型流写入失败或回复超过本地保存上限时会中止生成，保留最后成功保存的部分并标为流中断。导入档案和打开旧存档会检查关键数据结构；损坏的浏览器存档会进入恢复页，保留原始数据供下载。

## 实现与现有限制

业务状态在 `src/game/engine.ts`，准入在 `src/game/access.ts` 与 `src/Onboarding.tsx`，内容分类在 `src/game/contentPolicy.ts`，浏览器模型客户端在 `src/game/provider.ts`，本机网关在 `server/gateway.ts`，界面在 `src/ClientApp.tsx` 与 `src/DevTools.tsx`。存档与延迟检查恢复在 `src/game/persistence.ts`。

- 自定义提供方需要支持标准 SSE（OpenAI 兼容）或 NDJSON（Ollama）流。
- 目前只支持常见文本文件；PDF、图片等多模态文件还不能作为模型输入。
- HTML、SVG、JSX/TSX 等可独立查看的回复会列入 Artifacts，可编辑、复制并返回原消息；HTML/SVG 在禁用脚本、网络和表单的沙盒 iframe 中预览。JSX/TSX 当前仅支持查看与编辑，不执行预览。普通代码块仅提供复制按钮。
- 相同种子可以重新开始实验，但尚不能自动重放一整串历史操作。
- 聊天中的“正在思考”是等待状态；不会展示模型私有推理内容。
- 浏览器验收使用本机模拟的 OpenAI 兼容与 Ollama 流服务，验证正常流、并发会话、模型拒答、HTTP 403/500、安全拦截、流中断、停止生成、服务离线和真实 30 秒超时；没有调用真实付费模型。WSL2 私有 IP 的白名单配置已经验证，但当前环境没有可用的 WSL2 Ollama 模型服务，因此没有真实 WSL2 回答的通过记录。
- 模型配置另有浏览器验收和进程重启测试：失败保存会显示错误；成功保存、刷新页面及完整停止并重新启动本机 Node 网关后，提供方地址、模型映射和密钥仍可用于模拟流请求。测试使用独立临时配置文件，不会覆盖日常使用的模型配置。
- 跨标签页写入采用本地存档版本比较与冲突提示。只读打开的标签页不会在加载时无故重写正在生成的存档；生成中的回复使用短时租约，避免另一个标签页把它误判为中断。刷新原标签页后会标记中断。极端情况下，两个标签页恰好同时写入的 localStorage 操作仍没有数据库级原子事务保证。建议一个账号只在一个标签页中编辑。
- 存档无法解析时会显示恢复页，允许下载原始数据后手动清除；不会自动覆盖原文件。
- 网关在保存配置和发起请求时检查目标地址，并禁止跳转；对恶意 DNS 重绑定没有做到连接级地址固定。如需在不可信网络环境下使用，应进一步加固。
- 页面、聊天标记及浏览器标签图标使用用户提供的 `public/brand-icon.png`；本项目始终标注为非官方模拟，也不保证与实时生产界面逐像素一致。
